# Просто вкусно — домашние рецепты

Статический сайт для https://recipe.generalova.cc. Node.js 22+, без зависимостей и без серверной части.

## Сборка

```sh
npm run build
npm test
```

Готовые страницы находятся в `dist/`. Для локального просмотра после сборки: `python3 -m http.server 8080 --directory dist`.

## Cloudflare Pages

Подключите этот GitHub-репозиторий в Cloudflare Pages:

- Production branch: `main`
- Framework preset: None
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: корень репозитория
- Environment variable: `NODE_VERSION=22`
- Опционально: `SITE_URL=https://recipe.generalova.cc` (значение по умолчанию)

Подключение домена и автоматической сборки по коммиту выполняется в Cloudflare отдельно. Сайт не требует API-ключей. Не добавляйте SPA fallback: `404.html` обеспечивает настоящую страницу ошибки.

## Добавить рецепт

Создайте файл `recipes/название.md` по образцу существующих. В начале обязателен блок:

```md
---
title: Название блюда
slug: permanent-recipe-name
image: /images/permanent-recipe-name.png
category: Салаты
description: Короткое описание.
time: 30 минут
servings: 4
---

## Ингредиенты
- Продукт — 100 г

## Приготовление
### 1. Первый шаг
Текст шага.
```

Поддерживаются заголовки `#`, `##`, `###`, абзацы (один абзац на строку), списки `- ` и `1. `, выделение `**жирным**`. Это ограниченное подмножество Markdown; HTML, изображения, ссылки, таблицы и вложенные списки не поддерживаются. Разметка экранируется. Метаданные — простые строки `ключ: значение`, без кавычек и YAML-структур.

`slug` формирует постоянный адрес `/recipes/permanent-recipe-name/`. Не меняйте его после публикации, чтобы старые ссылки продолжали работать. Новая категория автоматически добавляется в фильтр. Поиск работает по названию и описанию.

Шаблон страницы: `templates/layout.html`. Генератор: `scripts/build.mjs`. Стили и браузерные действия: `public/`. Список файлов рецептов определяет порядок карточек (алфавитный).

Сайт содержит Open Graph заголовки и описания, canonical URL, sitemap, robots.txt, кнопку отправки ссылки с резервным копированием, печатную версию. Без JavaScript все рецепты и навигация доступны. Фотореалистичные иллюстрации созданы ИИ; файлы находятся в `public/images/`. На сайте есть подпись об этом. Чтобы заменить картинку, загрузите свой файл в эту папку и укажите путь в метаданных рецепта: `image: /images/имя-файла.png` (латиница, цифры и дефисы; PNG, JPG или WebP).

«Розовое облако» перенесено из сохранённого авторского PDF; оценка времени добавлена отдельно. Остальные блюда — базовые домашние версии, подготовленные для первой версии сайта, а не восстановленные тексты прежних чатов.

## Языки

Русский: `/`, английский: `/en/`, сербский (латиница): `/sr/`. Существующие русские ссылки сохранены. Переключатель RU / EN / SR открывает тот же рецепт на выбранном языке и работает без JavaScript. Каждый адрес можно отправить отдельно; автоматического перенаправления по языку браузера нет.

Русские рецепты остаются в `recipes/*.md`. Полные переводы хранятся в `recipes/en/*.md` и `recipes/sr/*.md` с теми же именами файлов и значением `slug`. При добавлении рецепта создайте все три версии: сборка остановится, если перевода нет или slug не совпадает. Переводите title, category, description, time, servings (если там слова) и весь текст, сохраняя количества и единицы. Общие изображения используются во всех языках.

Интерфейс, заголовки, подписи и сообщения: `scripts/i18n.mjs`. Страницы содержат соответствующие `lang`, canonical и hreflang; sitemap включает адреса всех языковых версий. Страницы ошибок создаются для всех языков; Cloudflare выбирает страницу 404 по своей маршрутизации. Тесты проверяют все языковые версии, переключатели на соответствующий рецепт, локальные ссылки и отсутствие русского текста в переводах.
